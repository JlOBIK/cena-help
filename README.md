# Cena — suporte

Um jogo de perguntas de cinema para iPhone. O conteúdo está em português do Brasil e funciona sem conexão com a internet.

## Como jogar

Escolha Partida completa, Partida rápida ou Desafio do dia. É possível jogar sozinho ou reunir de 1 a 6 pessoas no mesmo iPhone. Os nomes são opcionais.

## Pausar e continuar

Use o menu de pausa. Ao sair do aplicativo, o tempo da pergunta para. Ao retornar, continue a partida. Somente partidas concluídas aparecem no histórico.

## Som e vibração

Abra Ajustes para ativar ou desativar os efeitos sonoros e a resposta tátil. O modo silencioso e o volume do iPhone também podem afetar o som.

## Resultados salvos

Partidas, nomes opcionais, preferências e conquistas são guardados no aparelho. Apagar o aplicativo também apaga esses dados locais. O aplicativo não possui uma conta nem um servidor para recuperar resultados.

## Relatar um problema ou enviar uma sugestão

[Abra um chamado de suporte](https://github.com/JlOBIK/cena-help/issues/new). Informe a versão do iOS, o modelo do iPhone e os passos para reproduzir o problema. Não publique senhas, dados pessoais ou imagens com informações privadas. O GitHub exige uma conta para criar chamados; o jogo não exige conta.
